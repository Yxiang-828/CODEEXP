# CODEEXP Demo Audit — 2026-05-29

## Executive Summary

The app LOOKS like a crisis response system but BEHAVES like a static
mock. Cross-role flows are wired in AppContext but the seed data
obscures them. For a 3-tester demo (citizen, CFR, ops) we need:

1. Organic data flows (actions create data, not seed)
2. A clear test script with exact playout steps
3. No dead-end buttons or stub workspaces
4. Role persistence per browser session
5. A "self" identity that isn't hardcoded to Echo-1

---

| File | What's hardcoded | Impact |

| `CitizenWorkspaces.tsx:33-41` | Incident guidance text by `event.kind` switch | Hardcoded strings, not from data. |
| `LeftRail.tsx:32` | Bulletin count hardcoded to `5` | Never reflects actual events. |
| `LeftRail.tsx:33` | Assignments count hardcoded to `1` | Never reflects actual SOS assignments. |

## 4. Cross-Role Flow Gaps

Flow: **Citizen Report → Responder Verify → Ops Event**
- ✅ Citizen `fileReport()` writes to `reports[]`
- ✅ Appears in responder Verify queue
- ✅ Appears in ops Reports queue
- ❌ Responder clicks Verify → `claimReport()` + `verifyReport()` → but the
  verify button auto-claims AND auto-verifies in one click. No separate
  claim step visible.
- ⚠️ `verifyReport` always creates event with severity 3. Should use
  report's inferred severity.

Flow: **Citizen SOS → Ops Dispatch → Responder Assignment → Live Tracking**
- ✅ Citizen `startSos()` writes to `sosSessions[]`
- ✅ Tracking pill appears
- ✅ Appears in ops Distress queue
- ✅ Ops `assignSos()` updates responder status + tracking
- ✅ Responder position ticker animates (600ms interval)
- ❌ No auto-advance when responder arrives. Stays `en_route` forever
  unless manually clicked.
- ❌ No route line rendered on map for the assigned responder.

Flow: **Ops Declare → All Roles See Event**
- ✅ `declareIncident()` writes to `events[]`
- ✅ Events appear on map
- ❌ Drawing polygon doesn't auto-fill the declare form
- ❌ No role-preview gate actually enforced (it exists in UI but
  `allSeen` state is local to the Declare component, not persisted)

---

## 5. Recommendations (in priority order)

### Must-fix before demo
1. Reduce seed to 1 event + 1 report. Make everything else come from actions.
2. Add `localStorage` role persistence + responder self-selection.
3. Create `TEST_SCRIPT.md` with exact 3-person playout.
4. Wire dead buttons (Share, I am safe, Broadcast send).
5. Add "Inject test event" panel for ops (demo fallback).
6. Auto-advance SOS on responder arrival (auto `arrived` when <30m).

### Should-fix if time
7. Make FormCase functional (create case from drawn polygon).
8. Update `sources` array when live data is fetched.
9. Add General chat room.
10. Severity from report should be selectable, not hardcoded.

### Nice-to-have
11. Add a "Reset demo" button in ops settings.
12. Show toast notifications when cross-role events happen.
